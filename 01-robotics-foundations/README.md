# 01 · Robotics Foundations

## Scope

Understand a robot as an integrated physical and computational system. Learn the vocabulary used to discuss manipulators, autonomy, and task performance before studying motion mathematically.

## Learning objectives

By the end of this section, you should be able to:

- Identify the mechanical, electrical, sensing, and software parts of a robotic system.
- Explain how a manipulator relates to a complete robot.
- Distinguish programmed behavior, remote operation, and autonomy.
- Explain why accurate motion requires more than issuing a software command.

## Prerequisites

No robotics background is required.
