# 06 · Robot Programming

## Scope

Turn task descriptions into taught motions, simulated programs, and explicit execution logic. These lessons explain the workflow without requiring a particular robot brand or software installation.

## Learning objectives

- Distinguish online teaching from offline program preparation.
- Explain teach pendants, lead-through teaching, and playback.
- Identify what simulation validates and what still depends on the real installation.
- Separate programming languages, robotics frameworks, and robot controllers.
- Describe a task using states, measured conditions, and failure transitions.

## Prerequisites

[Frames and kinematics](../03-kinematics-foundations/README.md), [control](../04-control-and-interaction/README.md), and the basic grasping sequence in [perception and grasping](../05-perception-and-autonomous-grasping/README.md). No programming-language experience is required for the pseudocode.
