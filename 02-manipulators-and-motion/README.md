# 02 · Manipulators and Motion

## Scope

Describe manipulator structure and the independent variables needed to specify motion. Connect mechanical arrangement to tool capabilities and reach.

## Learning objectives

- Identify links, joints, the base, and the end effector.
- Distinguish common joint types and manipulator arrangements.
- Count configuration degrees of freedom in simple mechanisms.
- Distinguish joint configuration from tool pose.
- Explain workspace, redundancy, and singularity at an introductory level.
- Compare serial, parallel, mobile, humanoid, hybrid, and soft robot structures.
- Distinguish joint motion types from actuation and choose tooling using load and task constraints.

## Prerequisites

[Robotics foundations](../01-robotics-foundations/README.md) and basic algebra. No matrix calculations are required in this section.
